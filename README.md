# نظام ذكي للكشف عن إشغال مواقف السيارات

# Smart Parking Occupancy Detection System

هذا المشروع عبارة عن نظام ذكي يعتمد على الرؤية الحاسوبية (Computer Vision) والذكاء الاصطناعي (AI) لمراقبة وتحليل حالة مواقف السيارات في الوقت الفعلي. يستخدم النظام نموذج YOLO لتصنيف المواقف إلى "مشغولة" أو "فارغة" ويقوم بإرسال البيانات إلى وحدة تحكم خارجية (ESP32) عبر المنفذ التسلسلي (Serial).

## 🌟 المميزات (Features)

- **مراقبة لحظية (Real-time Monitoring):** استخدام الكاميرا لمراقبة المواقف بشكل مستمر.
- **دقة عالية:** يعتمد على نموذج YOLO المدرب (Classification Model) لتحديد حالة كل موقف بدقة.
- **تحديد يدوي للمواقف:** أداة سهلة وسريعة لرسم حدود مواقف السيارات على الصورة وتحديد أماكنها بدقة.
- **ربط مع الأجهزة (IoT Integration):** إمكانية إرسال حالة المواقف (0 للمواقف الفارغة، 1 للمشغولة) إلى متحكم ESP32 للتحكم في الإضاءة أو الشاشات.
- **واجهة مرئية:** عرض الفيديو المباشر مع تلوين الموقف بالأخضر (فارغ) أو الأحمر (مشغول).

## 🛠️ المتطلبات (Requirements)

تأكد من تثبيت **Python 3.8+** على جهازك. ستحتاج إلى المكتبات التالية:

- `opencv-python`: لمعالجة الصور والفيديو.
- `ultralytics`: لاستخدام نموذج YOLO.
- `pyserial`: للتواصل مع الـ ESP32.

## 🚀 التثبيت (Installation)

1.  قم باستنساخ المستودع (Clone) أو تنزيل الملفات.
2.  قم بتثبيت المكتبات المطلوبة باستخدام الأمر التالي:

```bash
pip install opencv-python ultralytics pyserial
```

> **ملاحظة:** إذا كان لديك ملف `requirements.txt` يمكنك استخدامه، ولكن الكود يعتمد بشكل أساسي على المكتبات المذكورة أعلاه.

## 📖 طريقة الاستخدام (Usage)

### 1. تحديد أماكن المواقف (Configuration)

قبل تشغيل النظام لأول مرة، يجب عليك تحديد إحداثيات مواقف السيارات الخاصة بك.

1.  شغل السكربت الخاص بالتحديد:
    ```bash
    python src/select_parking_spots.py
    ```
2.  اضغط على زر **'s'** لالتقاط صورة وتثبيتها.
3.  استخدم الفأرة لرسم مربعات حول كل موقف سيارة (مثلاً 6 مواقف).
4.  بعد الانتهاء، اضغط **'q'** للخروج.
5.  سيقوم البرنامج بطباعة كود مصفوفة `PARKING_SPOTS` في التيرمينال.
6.  انسخ هذا الكود وضعه داخل ملف `config/parking_spots.py`.

### 2. تشغيل النظام (Run System)

بعد تهيئة الأماكن، يمكنك تشغيل النظام الأساسي:

```bash
python src/live_system.py
```

- سيقوم البرنامج بفتح الكاميرا وبدء تحليل المواقف.
- تأكد من توصيل الـ ESP32 إذا كنت ترغب في استخدام ميزة الاتصال التسلسلي (تأكد من رقم المنفذ `COM10` في الكود أو قم بتعديله).
- لإيقاف البرنامج، اضغط على زر **'ESC'**.
